## 这是什么

一套面向**百万字级长篇小说**的长时记忆系统，以及把它接入 DSH 的插件。

核心主张：

```
大模型负责「想写什么、什么时候查」
本地小模型负责「查得快、查得准」
末影箱负责「记得住、管得好」
```

明确不做：纯上下文压缩 / 把整本书塞进窗口 / 靠模型硬记。

## 三个记忆库的分工

| 库 | 文件 | 存什么 | 生命周期 |
|---|---|---|---|
| **作品库** | `works/<名称>-<哈希>.db` | 人物/世界/时间线/伏笔/物品 | 跟作品走 |
| **全局文学库** | `global.db` | 写作手法、叙事节奏、风格选型 | 跨作品复用 |
| **技术库** | `tech.db` | 事故复盘（案例）+ 可执行断言 | 跨项目复用 |

路由规则在 `memory.py:route()`：`style` → 全局，`assertion` → 技术库，其余 → 作品库。

## 快速开始

```bash
# 环境自检
python -m enderwriter info

# 检索
python -m enderwriter recall 白杨

# 技术护栏
python -m enderwriter guard --task "回写 DLL"

# 导出设定集
python -m enderwriter export --work 涟城 --save 设定集.md

# 跑测试
python -m unittest discover -s tests
```
