### 工具注册

```js
function registerTool(def) {
  const originalExecute = def.execute
  def.execute = async (args, toolCtx) => {
    // 记录最近活跃会话（面板需要）
    const sid = toolCtx?.agent?.id
    if (sid) lastActiveSession = sid
    return originalExecute(args, toolCtx)
  }
  return ctx.tools.register(def)
}
```

**为什么需要 `lastActiveSession`**：Web 面板挂在 root 作用域，拿不到"当前是哪个会话"。所以由 Host 记录最近活跃的会话。

### HTTP 路由

面板通过 HTTP 取数（不是 RPC —— 该 DSH 版本的 Client 半边没有 host 服务）。

```js
const routes = [
  '/api/enderwriter',
  '/api/enderwriter/overview',
  '/api/enderwriter/entries',
  '/api/enderwriter/works',
]
```

支持 GET（读）和 POST（写，正文太长走 body）。

**权限**：只允许 GET/POST + 本机来源。

### 端点清单

| 端点 | 方法 | 作用 |
|---|---|---|
| `overview` | GET | 面板全部数据 |
| `entries` | GET | 某图层的条目列表 |
| `update` | POST | 编辑正文（生成新版本） |
| `forgetEntry` | POST | 删除单条 |
| `clear` | POST | 清除整库（带备份） |
| `history` | GET | 版本历史 |
| `revert` | POST | 回滚到某版本 |
| `archive` | POST | 标记回收归档 |
| `setEnabled` | POST | 面板开关 |

### 服务获取

```js
// 必须在文件顶部 inject 声明，否则 Cordis 不注入
export const inject = ['tools', 'webServer', 'connection']

// 之后直接访问 ctx.webServer
```

**踩过的坑**：`ctx.get('webServer')` 拿不到东西，必须用 `inject` 声明 + 属性访问。

## Client 半边（client.js）

### 注册点

```js
return {
  inject: ['slots'],
  apply(ctx) {
    // 侧边栏图标
    ctx.slots.inject('sidebar.panellist', () =>
      ctx.slots.register({ name: 'sidebar.panellist', id: 'enderwriter',
                           order: 20, label: '末影箱' }, PanelIcon))

    // 主面板
    ctx.slots.inject('main', () =>
      ctx.slots.register({ name: 'main', key: 'enderwriter' }, SafePanel))
  }
}
```

**`inject` 只声明 `slots`** —— 声明不存在的服务会让插件永久 pending，连图标都不显示。

### 三个交互全部原地展开

**这是本轮最大的改动。** 之前用 `position: fixed` 的遮罩弹层，在宿主 UI 里**渲染了但不显示**。

现在：

| 操作 | 展开位置 |
|---|---|
| 编辑 | 条目行内 → 文本框 + 保存/取消 |
| 历史 | 条目行内 → 版本列表 + 回滚按钮 |
| 删除 | 条目行内 → 确认块 + 勾选框 |

```
测试条目                       v2
正文内容……

┌────────────────────────────────────────┐
│ ⚠ 删除词条「测试条目」                  │
│ 图层：world                             │
│ 内容：正文内容……                        │
│ 删除后该词条不再参与检索。会先备份。     │
│                                         │
│ ☐ 我已确认要删除「测试条目」            │
│                       [取消] [确认删除] │ ← 未勾选时灰
└────────────────────────────────────────┘
```

**为什么必须原地**：弹层会跑到视野之外（顶部）或被遮住，表现出来的就是"点了没反应"。

### 搜索

```js
const filterBySearch = (items, pickName, pickBody) => {
  const q = search.trim().toLowerCase()
  if (!q) return items
  const hitName = [], hitBody = []
  for (const it of items) {
    if (pickName(it).toLowerCase().includes(q)) hitName.push(it)
    else if (pickBody(it).toLowerCase().includes(q)) hitBody.push(it)
  }
  return hitName.concat(hitBody)   // 名字命中排前面
}
```

三个区块（作品 / 全局文学 / 技术）走同一套 `searchBox` + `entryRow` + `searchEmpty`。

### 样式

全部用 CSS 类名，从 `ctx.styles.insert(CSS)` 注入（拿不到时兜底 `document.head.appendChild(<style>)`）。

颜色一律走宿主主题令牌：

```css
background: var(--dsw-alias-bg-base);
color: var(--dsw-alias-label-primary);
border: 1px solid var(--dsw-alias-border-l1);
```

**没有硬编码颜色**，明暗主题自动跟随。

## 配置

### cordis.patch.yml

```yaml
- insert:
    - id: enderwriter
      name: 'dsh-enderwriter'
      config:
        root: ''        # 留空 = 自动探测
        python: ''      # 留空 = 自动探测
        defaultBudget: 800
        enabled: true
        work: ''        # 留空 = 每个对话独立记忆
```

```json
{
  "name": "dsh-enderwriter",
  "version": "1.1.0",

  "exports": {
    ".": "./index.js",

```

## 安装

```bash
# 1. 确认 Python
python -c "import sqlite3; print('ok')"

# 2. 安装插件
dsh plugin add /path/to/dsh-enderwriter-plugin

# 3. 重启 DSH
```

自动探测包根和解释器，通常不需要改配置。

## 故障排查

自检文件写在 `memory/` 下：

| 文件 | 内容 |
|---|---|
| `plugin-diag.json` | 服务探测结果、root/python 实际值 |
| `plugin-route.txt` | HTTP 路由注册结果 |
| `plugin-overview.json` | 最近一次 overview 调用的诊断 |

看 `plugin-diag.json` 的 `root` / `python` 是否为 null：

```json
{
  "root": "C:\\...\\enderwriter",
  "python": "C:\\...\\python.exe",
  "rootResolved": true,
  "pythonExists": true,
  "webServer": true,
  "hasRegister": true
}
```

两者都 true 才正常。
